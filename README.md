# Taichu Lab Official Website

Taichu Lab official website — a simple static HTML site deployed via GitHub Pages.

**Live:** [https://taichulab.github.io](https://taichulab.github.io)

**Repo:** [https://github.com/taichulab/taichulab.github.io](https://github.com/taichulab/taichulab.github.io)

## Structure

```
.
├── index.html          # Single-page site
├── assets/             # Images & fonts
└── .github/workflows/  # GitHub Pages auto-deploy
```

## Development

Just open `index.html` in a browser — no build step required.

## Deployment

Push to `main` and GitHub Actions automatically deploys to GitHub Pages.
